# Прогнозирование утечек в газовых трубопроводах

![Java](https://img.shields.io/badge/Java-21%2B-blue)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.4.2-green)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Система прогнозирования утечек в газовых трубопроводах с веб-интерфейсом для визуализации данных.

## 📖 О проекте

Проект предоставляет:

- Предсказательную модель для оценки вероятности утечек;
- Автоматическое определение отклонений поступательных данных на основе математических расчетов;
- Визуализацию данных через интерактивные графики (Chart.js);
- Адаптивный веб-интерфейс с возможностью выбора датчиков;
- Автоматическое обновление прогнозов на заданный период.

В репозитории расположены 2 модуля:

- LoT - просто пример датчика интернет вещей;
- Monitor - сам сервис сбора и анализа данных.

## 🛠 Технологии

- **Backend**:
    - Java 21;
    - Spring Boot, Web, Data 3.4.2;
    - Lombok;
    - Куча всякой математики от которой у меня болит голова.

- **Frontend**:
    - Thymeleaf;
    - Chart.js 4.4.0;
    - Luxon (для работы с датами).

- **База данных**: PostgresSQL в Docker Compose(для демонстрации)

## 🚀 Требования для запуска

- Java 21;
- TomCat 11.
